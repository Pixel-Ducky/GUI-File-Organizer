# GUI-File-Organizer
You choose a Folder and it will organise the files inside. It may leave the folder empty.

You have a Folder , named cat, with mixed files.  
You want to organize the files. In GUI choose 'cat'.  

.jpg .png .jpeg .gif  .jfif   --> Pictures\pics  
.pdf .epub --> Desktop\Books  
.docx .pptx .xls -->Documents\Folder_Projects  
.txt --> Documents\Folder_Notepad  
.mp4 --> Documents\Folder_Video  
.mp3 -->Documents\Folder_Audio
